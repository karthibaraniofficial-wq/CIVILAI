# CIVICFLOW AI — Release Notes

## Version 0.1.0-alpha (Milestone 1 — Initial Foundation)
### Summary
Foundation release establishing project structure, typed schemas, database DDL, multi-agent contracts, FastAPI backend, and React/Tailwind frontend shell.

### Highlights
- Comprehensive database schema DDL covering 14 relational entities.
- Unified multi-agent interface (`BaseAgent`) with Pydantic validation and audit logging.
- Dual persistence strategy ready for Supabase or offline local SQLite.
- Clean citizen and municipal operations shell with responsive typography and theme tokens.
